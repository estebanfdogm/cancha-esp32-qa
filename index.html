Usar en Android

Esta entrega es el diseño interactivo y el control web para PC. La aplicación Android nativa y su APK están pendientes. La misma interfaz puede probarse con Chrome Android si se sirve desde HTTPS.

Antes de conectar

El robot necesita el firmware CanchaC3 incluido. El firmware inicia con las salidas físicas bloqueadas hasta verificar el cableado y la calibración del servo.
